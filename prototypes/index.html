Prototipos de inicio · Brigada Galgos

Cinco direcciones visuales para la página de inicio. Cada propuesta conserva el mismo contenido real y el mismo orden de nueve secciones; solo cambia el sistema visual.

  • Editorial documental Serif display + sans body, columnas de lectura estrechas, pies de foto documentales, paleta tinta/papel.
  • Cálido doméstico Neutros cálidos, redondez contenida, la fotografía de vida hogareña lidera la composición.
  • Tipográfico audaz Display condensado de gran tamaño, monocromo + un acento, composición que rompe la grilla.
  • Clínico transparente Primero la confianza, grupos de datos estructurados, paleta fría y contenida, secuencia del proceso.
  • Territorial chileno Paleta terrosa del paisaje chileno, bandas texturadas, secuencia horizontal de casos.
