# Glossary

Bilingual map of the Spanish domain terms that appear in schemas, routes, copy, and CSS. Use it when editing content or code so the same concept keeps the same word everywhere. The copy rules behind these terms live in `docs/voice-and-tone.md`.

A general spelling rule that applies to several rows below: **schema enum values are unaccented or exact-match strings, but display copy always keeps correct Spanish accents**, including in uppercase. Write "ADOPCIÓN", never "ADOPCION". Real examples: the "ADOPCIÓN" eyebrow in `src/config/faq.ts`, "EN ADOPCIÓN HOY" in `src/components/sections/FeaturedAdoptionDogs.astro`, and "GALGO EN ADOPCIÓN" in `src/pages/adoptar/[slug].astro`. The rationale is documented in a comment in `src/styles/global.css`: Spanish accents survive `text-transform`, so uppercase is no excuse to drop them.

## Editing Rules Derived from the Table

- Never "fix" the unaccented enum values `adopcion` or `exito` to carry accents; they are discriminators in `src/content.config.ts` and must match the frontmatter exactly.
- Never let the unaccented schema spelling leak into display copy: visitors always read "Adopción", "Éxito", "información".
- When a `status: "adopcion"` dog is adopted, the profile URL is retired with a `/adoptar/<slug>/ /casos-de-exito/ 301` entry in `public/_redirects`; the full workflow is in `docs/content-model.md`.
